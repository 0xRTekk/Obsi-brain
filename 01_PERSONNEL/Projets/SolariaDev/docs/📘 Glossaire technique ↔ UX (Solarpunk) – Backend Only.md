## 🧩 Entités principales du domaine

| 🛠️ Terme technique (backend) | 🌿 Terme UX Solarpunk | 🧭 Rôle et description |
|-----------------------------|------------------------|------------------------|
| `User` | **Jardinier·ère** | Utilisateur de la plateforme (dev ou entreprise). Cultive ses compétences et contribue à l'écosystème. |
| `UserProfile` | **Oasis** | Profil du développeur représenté comme un espace vivant. Sert de hub personnel. |
| `CompanyProjectBrief` | **Graine d’Entreprise** | Défi réel proposé par une entreprise pour résoudre un besoin concret. Point de départ d’un projet. |
| `Project` | **Floraison** | Projet concret initié à partir d’une Graine. Peut être solo ou collaboratif. |
| `ProjectTeam` | **Essaim** | Groupe de développeurs qui collaborent pour cultiver une Floraison. |
| `Submission` | **Pollinisation** | Soumission d'une solution ou d'une contribution à un projet. Peut être évaluée. |
| `Skill` | **Capacité** | Compétence acquise ou mobilisée sur un projet. |
| `SkillTree` | **Arbre de Connaissance** | Organisation et visualisation des capacités acquises. |
| `Badge` | **Totem** | Objet symbolique représentant un accomplissement (technique, soft skill, mentorat...). Peut être placé dans l’Oasis. |
| `PortfolioProject` | **Éclat** / **Module** | Projet finalisé et intégré dans le portfolio du dev. Visible dans son Oasis comme un objet ou une structure. |
| `XP` | **Énergie vitale** | Ressource abstraite générée par les actions (pollinisation, mentorat, progression...). Sert à faire évoluer son profil. |
| `Level` | **Canopée** | Palier d'évolution global du développeur. |
| `Mentorship` | **Pollinisateur·rice** | Acteur qui aide un autre jardinier sur un projet ou dans sa progression. |
| `Feedback` | **Brise** | Retour laissé par une entreprise ou un autre jardinier sur une action. |
| `Notification` | **Rayon solaire** | Message informatif ou déclencheur d’action. |
| `CommunityZone` | **Jardin partagé** | Espace communautaire d’échange, de publication ou de collaboration. |

---

## ⚙️ Objets système liés à la progression ou à l’Oasis

| 🔧 Élément technique | 🌻 Terme UX Solarpunk | 📌 Description |
|---------------------|------------------------|----------------|
| `XP Gain Event` | **Infusion** | Action qui génère de l’énergie vitale (dépôt de projet, feedback, badge reçu...). |
| `UnlockableAsset` | **Artefact** | Élément décoratif ou fonctionnel à débloquer dans l’Oasis avec l’énergie vitale. |
| `Customisation` | **Agencement** | Organisation libre de son Oasis (placement des Totems, Modules, Arbre, etc.). |
